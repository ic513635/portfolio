# Ally Lin Portfolio

A static portfolio website built with HTML, CSS, and vanilla JavaScript. No package installation or build step is required.

## Files

- `index.html` — portfolio homepage
- `case.html` — project case studies, rendered from `app.js`
- `cv.html` — CV page
- `styles.css` — site styling and responsive layouts
- `app.js` — project data, page rendering, navigation, and email-copy interaction
- `public/images/` — project visuals

## Deploy to Vercel

Import this repository in Vercel. Select **Other** as the framework preset, leave the build and install commands empty, and use `.` as the output directory. The site is served from `index.html` at the repository root.
